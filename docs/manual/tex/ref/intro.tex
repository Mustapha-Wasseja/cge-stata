\chapter*{Introduction to the command reference}\label{ref:intro}
\addcontentsline{toc}{chapter}{Introduction to the command reference}
\markboth{Introduction to the command reference}{}

This part describes each command of \pkg, in alphabetical order. Each entry
follows the order of the entries of Stata's own manuals: a description, short
examples (Quick start), the syntax and its options, remarks and examples with
their output, the results stored in \cmd{r()}, the methods and formulas, and
related entries. The formulas of the model are stated once, in
Part~\ref{part:model}; each entry gives the formulas of its own command and
refers to Part~\ref{part:model} for the rest.

In a syntax diagram the command is in bold type, arguments are in italics, and
the underlined part of an option is its shortest abbreviation; an option with
nothing underlined cannot be abbreviated. Options in square brackets are
optional.
