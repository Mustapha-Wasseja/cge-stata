\cgeentry{cge_parameters}{The calibrated parameters as a dataset}

\cgesec{Description}

\cmd{cge_parameters} replaces the data in memory with the parameters of the
model, one observation per parameter element, with the string variables
\cmd{parameter}, \cmd{element1} and \cmd{element2} and the numeric variable
\cmd{value}. It gives the base (calibrated) parameters, the parameters of a
stored simulation, or the current parameters, including shocks not yet solved.
Use it to inspect, document or compare a calibration.

\cgesec{Quick start}

Load the calibrated parameters and list the import tariff rates
\begin{stcode}
cge_parameters, clear
list if parameter == "tm"
\end{stcode}
Load the parameters of the simulation \cmd{notariff}, with its shocks
\begin{stcode}
cge_parameters, clear sim(notariff)
\end{stcode}
Load the current parameters, with the shocks set since the last solve
\begin{stcode}
cge_parameters, clear current
\end{stcode}

\cgesec{Syntax}

\begin{stsyntax}
\cmdb{cge_parameters}\texttt{,} \opt{}{clear} [\argu{options}]
\end{stsyntax}

\begin{opttable}
\optgroup{Main}
\opt{}{clear} & replace the data in memory; required\\
\optarg{}{sim}{name} & parameters of a stored simulation\\
\opt{cur}{rent} & current parameters, including shocks not yet solved\\
\end{opttable}

\cgesec{Options}

\begin{optdesc}
\item[\opt{}{clear}] is required: the data in memory are replaced. The model
itself, which is kept in Mata, is not changed.

\item[\optarg{}{sim}{name}] gives the parameters of a stored simulation,
including its shocks. By default the base (calibrated) parameters are given.

\item[\opt{cur}{rent}] gives the current parameters, including the shocks set
with \manref{cge_shock} since the last solve. \cmd{sim()} and \cmd{current}
may not be combined.
\end{optdesc}

\cgesec{Remarks and examples}

Each parameter is stored by element: a parameter of commodities has one
observation per commodity, with the commodity in \cmd{element1}; a parameter of
two sets, such as the intermediate input coefficients, has one observation per
pair, with the second element in \cmd{element2}; a scalar parameter has one
observation with both elements empty. Every element of the set is listed,
including elements to which the parameter does not apply; these hold a value
that the model does not use, such as an export tax rate of zero for a
commodity without exports. The names of the parameters are those of the table
below.

\cgesubsec{Example 1: tax rates and shares}

After the synthetic SAM is mapped and calibrated as in Example~1 of
\manref{cge_calibrate}:
\stlog{param_base}
The import tariff rate of \cmd{com_agr} is the tariff over the value of
imports, $2/20$. The sales tax rate is the tax over composite supply, which
includes the tax: for \cmd{com_agr}, with domestic sales of 80, imports of 20
at the price 1.1, which includes the tariff, and the tax of 8,
$\cmd{tq} = 8/(80 + 1.1 \times 20 + 8) = 8/110$.
A parameter of two sets lists every pair:
\stlog{param_matrix}
These are the shares $\delta^{va}_{fa}$ of the CES value-added functions;
with \cmd{sigmava(0.8)}, they differ from the factors' shares of value added in
the SAM (\secref{sec:cal-production}).

\cgesubsec{The parameters}

The parameters follow the notation of \secref{sec:parameters}. In the table,
$C$, $A$, $F$ and $H$ are the commodities, activities, factors and households,
$D$ the households and enterprises, $I$ the institutions that receive factor
income ($D$, the government, the rest of the world and, when mapped, the
health insurance fund) and $N$ the nests of value added.
