\cgeentry{cge_set}{User sets of elements, for indexes and sums}

\cgesec{Description}

\cmd{cge_set} defines a set of elements of the calibrated model, such as the
goods that are traded, the health commodities or the rural households. Its
name then serves as an index wherever the letter of a model set does: in the
definitions of user variables (\manref{cge_variable}), in user equations
(\manref{cge_equation}), in sums, and in the indexes of user parameters
(\manref{cge_parameter}).

\cgesec{Quick start}

The commodities other than services and health
\begin{stcode}
cge_set goods = c, except(com_ser com_hlt)
\end{stcode}
Government spending on them, as a user variable
\begin{stcode}
cge_variable GGOODS = sum(goods, PQ(goods) * QG(goods)), nominal
\end{stcode}
Display the user sets
\begin{stcode}
cge_set, list
\end{stcode}

\cgesec{Syntax}

Define a set
\begin{stsyntax}
\cmdb{cge_set} \argu{name} \cmd{=} \argu{elements} [\texttt{,} \optarg{}{except}{elements}]
\end{stsyntax}
Display or remove the user sets
\begin{stsyntax}
\cmdb{cge_set} \texttt{,} \opt{}{list}\\
\cmdb{cge_set} \texttt{,} \opt{}{clear}
\end{stsyntax}
\argu{elements} are labels of elements of the model (accounts, such as
\cmd{com_hlt}, or nests), letters of model sets (\cmd{a} activities, \cmd{c}
commodities, \cmd{f} factors, \cmd{h} households, \cmd{d} households and
enterprises, \cmd{i} institutions receiving factor income, \cmd{n} nests of
value added), and names of user sets, separated by spaces. \argu{name} has at
most 24 characters, letters, digits and underscores; it may not be the name
of a variable, a parameter, an element, a user equation or another user set,
nor an index letter of a model set.

\begin{opttable}
\optgroup{Main}
\optarg{}{except}{elements} & elements left out\\
\end{opttable}

\cgesec{Options}

\begin{optdesc}
\item[\optarg{}{except}{elements}] leaves out the elements listed, given as
for the set.

\item[\opt{}{list}] displays the user sets and their elements.

\item[\opt{}{clear}] removes every user set. A set that a user variable,
equation or parameter uses cannot be removed until they are.
\end{optdesc}

\cgesec{Stored results}

\cmd{cge_set} stores the following in \cmd{r()}:
\begin{storedres}
\resgroup{Scalars}
\res{r(N_elements)} & number of elements of the set defined\\
\res{r(N_sets)} & number of user sets (\opt{}{list})\\
\resgroup{Macros}
\res{r(name)} & name of the set defined\\
\res{r(elements)} & its elements\\
\end{storedres}

\cgesec{Methods and formulas}

A user set is an ordered list of labels. An expression is written out for
each element of the set of its index, and each sum over the elements of its
set (\chapref{chap:user}), so a user set changes only which elements are
written out; it adds no variables or equations of its own. In the GAMS
program the equations are written out element by element, so user sets need
no declaration there.
