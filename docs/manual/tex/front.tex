{\small
\textbf{cge-stata} builds, calibrates and solves computable general equilibrium
models in Stata: static and dynamic SAM-based models, regions linked by trade,
and standalone user-defined models. Its built-in solvers run in Stata and Mata
on Stata 13 or later; optional SciPy solver links require Stata 16 or later
with Python and SciPy.

The package and its source are at
\url{https://github.com/Mustapha-Wasseja/cge-stata}. This manual is built from
the LaTeX sources in \cmd{docs/manual/tex} with \cmd{tools/build_manual.py}.

The social accounting matrices shipped with the package and used in the
examples of this manual are SYNTHETIC: they are constructed for testing and
describe no country.\par}
