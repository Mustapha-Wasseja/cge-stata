. cge

cge-stata 0.6.4
Computable general equilibrium modelling in Stata

Preparing a SAM
  cge_sam         read a social accounting matrix, of any size, wide or long
  cge_template    write a template for roles and aggregation (Excel or CSV)
  cge_aggregate   merge accounts into groups
  cge_balance     balance the SAM by RAS or cross entropy
  cge_samexport   write the SAM to a file or to memory
  cge_multiplier  SAM multipliers and their decomposition
  cge_spa         structural paths of a SAM multiplier

Workflow
  cge_map         assign SAM accounts to model roles
  cge_calibrate   calibrate the model
  cge_elasticities published elasticities, with sources, as calibration options
  cge_closure     choose the closure
  cge_shock       change parameters or fixed variables
  cge_constraint  limits that may bind: quotas, capacity, borrowing and deficit ceilings
  cge_variable    user variables, defined by an expression or by user equations
  cge_equation    user equations: new relations among the model's variables
  cge_solve       solve and store a simulation
  cge_optimize    choose instruments to maximise an outcome or reach targets
  cge_dynamic     solve a recursive dynamic run, period by period
  cge_results     display or save all results of a simulation
  cge_report      standard report tables, to screen, Stata or Excel
  cge_dynresults  results of a dynamic run, against a baseline
  cge_sensitivity sensitivity of a scenario to the elasticities
  cge_microsim    pass a simulation to household survey data
  cge_check       run validation checks
  cge_parameters  calibrated parameters as a dataset
  cge_save        save the model and its simulations to a file
  cge_use         load a saved model
  cge_gams        write the model as a GAMS program; solve it with PATH, CONOPT or IPOPT

Data
  cge_synthetic   load the synthetic SAM used in tests and examples
