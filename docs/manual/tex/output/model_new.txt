. cge_model new
New standalone model: write its sets, parameters, variables and equations
with cge_set, cge_parameter, cge_variable and cge_equation, and solve it with cge_solve

. cge_set g = g1 g2
User set g: 2 element(s): g1 g2

. cge_set h = h1 h2
User set h: 2 element(s): h1 h2

. cge_parameter alpha(h,g), values(h1.g1:0.3 h1.g2:0.7 h2.g1:0.6 h2.g2:0.4)
User parameter alpha(h,g): 4 value(s), from .3 to .7

. cge_parameter e(h,g), values(h1.g1:10 h1.g2:2 h2.g1:3 h2.g2:8)
User parameter e(h,g): 4 value(s), from 2 to 10

. cge_variable P(g), value(1)
User variable P(g): 2 element(s), base values 1 1
Add the equations that determine it with cge_equation

. cge_variable Y(h) = sum(g, P(g) * e(h,g))
User variable Y(h): 2 element(s), base values 12 11
and its definition, equation Y

. cge_variable X(h,g) = alpha(h,g) * Y(h) / P(g)
User variable X(h,g): 4 element(s), base values 3.6 8.4 6.6 4.4
and its definition, equation X

. cge_variable WALRAS, value(0)
User variable WALRAS: 1 element(s), base value 0
Add the equations that determine it with cge_equation

. cge_equation NUM: P(g1) = 1
User equation NUM: 1 element(s)

. cge_equation MKT(g): sum(h, X(h,g)) = sum(h, e(h,g)) + WALRAS
User equation MKT: 2 element(s)
Note: the starting levels do not satisfy it (largest relative gap  2.19e-01)
